{{ _('Device Console') }}

Open a CLI session to an appliance, run commands, read every answer, and package the transcript for a Fortinet support ticket. Also tests a single username and password directly against a FortiOS device.

This console can change the appliance. It is the only place in SATOM where SSH writes. Two things follow, and neither is a bug:
  • The delete guard does not apply here. The web UI refuses to delete an object another policy still references; a CLI delete inside a config block is not something that guard can see.
  • Commands that end an appliance — execute factoryreset, execute formatlogdisk, disk formats — are refused at every permission level and have no path through this page. Reboots, config restores, HA changes and password writes are sent only after you acknowledge them and type the appliance name.
