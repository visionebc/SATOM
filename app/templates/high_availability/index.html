Node-to-node architecture — ports, channels & where the sync happens reference

Two roles the ports play — do not conflate them: :443 is the public web face (your browser → the app), while the node‑to‑node traffic rides three separate channels (:8443, :5432, SSH). The heavy sync — the standby's actual database — is Postgres streaming replication on :5432, not :8443. Live per‑channel encryption status is on the Monitoring → Encryption page.

Where the sync actually happens — three independent mechanisms, only one is app code:
  • Database — Postgres streaming replication, configured in postgresql.conf + pg_hba.conf. Native DB mechanism, not app code; this is why the standby is read‑only.
  • Files — deploy/satom-ha-datasync.sh (unit satom-ha-datasync.timer): the standby pulls data/ over rsync/SSH every 5 min (role‑guarded, inert on the primary).
  • App / code — app/services/reconciler.py (satom-reconciler.service, both nodes): DB‑free orchestration of the HA deploy mode (MANUAL/AUTO) and the staged code rollout. The only sync that is app code.
  • Device SoT → git — app/services/device_sync.py harvests each appliance's config; git_service.py + satom-git-publish.sh (primary‑only, hourly) publish it to Gitea over HTTPS.
  • Inter‑node auth — app/services/node_security.py::peer_get() signs the :8443 probes with the shared identity key; the node cert is managed in Settings → Node TLS.
Deployment mode {% if ha.mode == 'ha' %}HA — two-node {% else %}STANDALONE{% endif %}
HA: staged updates (the standby must validate a revision before the primary unlocks), active peer probing, manual failover, and the periodic data/ sync — all driven by the peer host registered in HA nodes below (never hardcoded). Standalone: every HA behavior above is off and updates apply directly to this node. The toggle governs the manager's behavior only — it does not build or tear down Postgres streaming replication (if configured, replication keeps running harmlessly underneath). Stored in the replicated settings: set it once on the primary and both nodes follow.
