A hook is a small Python script SATOM runs when it emits an event — for example, opening a CRQ in your own CRM when a change is requested. Hooks never execute inside the web application: saving one only writes it to disk, and a privileged runner (satom-integrations.service) executes it out of process, as an unprivileged user, with a hard timeout and only the secrets the hook declared.
