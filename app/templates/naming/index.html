Naming Scheme

Define the name pattern of each object. When creating a new object the operator only types the web address and the system derives every name from these patterns. Use the token {name} as the site identifier — it is sanitised automatically (shop.example.com → shop-example-com). Clearing a field restores its default pattern. Patterns are kept separately per product.
