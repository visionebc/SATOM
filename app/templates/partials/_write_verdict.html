{# The device re-read of an API-console write — ONE author for the badge the FortiWeb, FortiADC, FortiGate and FortiAuthenticator consoles draw next to the device's raw reply (services/device_verify.py builds the verdict). An accepted write is not proof of a change, so every applied write is read back and judged: "Verified on the device", "Not applied: ", or "Not verified: " — never a fake "verified". The raw reply above it stays exactly what the device answered; the verdict is additive. Usage: a in the page, and ``satomVerdictBadge(spanEl, response.verify)`` after each run (a read, a dry run or a refused write carries no verdict: the badge hides). #}
