What this page answers. A policy can be configured perfectly and still serve nothing, because the real servers behind it sit on a network the box cannot reach. That is a different question from "is the config right?", and it is the only one this page asks.

Three answers, never two. A backend is reachable, unreachable, or unknown. A probe that could not run is never reported as an outage and never as health.
