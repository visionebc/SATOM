Preflight — would this payload be understood?

Before writing a payload built against one line to an appliance running another, ask. satom get api preflight <appliance> <object> <field>… answers from this matrix, and the answer unmeasured is a real answer — it is never reported as compatible.

  • ok — every field is present on that line.
  • unknown_fields — named fields that line has never been seen to serve.
  • absent — the appliance rejected that URN on that line.
  • fields_unknown — the endpoint exists, but it answered with an empty collection, so nothing is known about its fields.
  • unmeasured — no evidence at all for that line. Sweep an appliance on it, or harvest its field schemas, before trusting a cross-line payload.
