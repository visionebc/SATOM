Operating mode {{ mode_current.label }}

A mode is a named set of values for the settings on this page and in Settings → Sentinel — nothing more. No gate anywhere asks which mode is active, so the name cannot describe a behaviour the knobs below do not have. The live mode is worked out from those values every time this page is drawn: change one by hand and it reads Custom at once, with the differing keys named. A label that survived a hand edit would be a claim about a posture that is no longer configured.

What a mode never touches, in either direction: ai_enabled, vuln_sync_enabled and the API key — whether this fleet's data leaves the node is consent, not sensitivity — and protect_cidrs and the hardened-profile list, which are the containment. Choosing “Ultra high” does not widen what may be blocked; it raises how readily it is proposed. The never-block list and the TTL are what stop it.
