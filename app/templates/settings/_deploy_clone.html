This pane never exports or imports in the web worker: both are queued for the privileged runner, which runs the installed CLI -- an import stops the very service that answers this page. What happens here is listing, the manifest preflight, the passphrase check, the queueing and the release. The export passphrase is chosen by the server when the export is queued and shown ONCE in this page.
