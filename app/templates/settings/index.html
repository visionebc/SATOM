Naming Scheme

Define the name pattern of each object in a Server Policy. When creating a new policy the operator only types the web address and the system derives every name from these patterns. Use the token {name} as the site identifier — it is sanitised automatically (shop.example.com → shop-example-com). Clearing a field restores its default pattern.

Device Classification

Catalogs used to classify appliances — Zones (network zones), Lines (service lines / environments) and Departments. Each appliance is assigned one value per catalog on its Edit page. One entry per line.

Network Segments

Named back-end networks (CIDR + interface + gateway) from which a new policy builds its server pool. Each segment can be scoped to a classification value (leave blank for "any").
