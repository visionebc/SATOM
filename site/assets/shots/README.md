# Screenshots — drop your SATOM web captures here

The gallery on `index.html` ("See it in action") auto-detects these files.
Until a file exists, its tile shows a clean dashed "screenshot pending"
placeholder. Drop the PNG in with the exact name and it renders + gets a
click-to-zoom lightbox automatically. No HTML edit needed.

| Filename                    | Caption on the site                                   |
|-----------------------------|-------------------------------------------------------|
| `dashboard.png`             | Dashboard — fleet health & device status              |
| `signatures.png`            | Signatures — FortiWeb WAF signatures & exceptions     |
| `templates.png`             | Templates — reusable policy templates with locks      |
| `object-editor.png`         | Object editor — spec-driven editor (~500 endpoints)   |
| `device-sync.png`           | Device sync — scheduled harvest & git source of truth |
| `backups.png`               | Backups & HA — four-copy coverage matrix              |

Recommendation: capture at ~1600×1000 (16:10), PNG. They're shown `object-fit:
cover` from the top, so the top of each screen matters most. Keep any
tenant/device names you don't want public out of frame.
